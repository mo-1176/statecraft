# 0004. 起動の親子を、コールスタックではなく表で持つ

- 状態: 採用
- 日付: 2026-11-19

## 決めたこと

エージェントは、委譲先の `execute()` を関数として呼ばない。ループは tool / agent を呼ぶ所で**呼び出しの計画（バッチ）を返して手を離し**、実行は起動の表（`runtime.py`）が受け持つ。委譲先はその表に子の起動として足され、親は「バッチの何番目の結果を待っているか」という1行のデータになる。

この上に、依頼の中断と再開（`suspend()` / `save_state()` / `load_state()` / `resume()`）を載せた。

## 困っていたこと

ヒューマンインザループ（tool が候補を利用者に見せ、選ばれたものがエージェントに届く）を入れようとして、今の設計では無理だと分かった。

サーバーで動かす前提では、利用者の返事をプロセスの中で待てない。いったん依頼を終えて状態を保存し、返事が来たら別のプロセスで続きから動かす必要がある。ところが、委譲を関数の呼び出しで表していると、止まった瞬間の親の情報がどこにもデータとして無い。

| 知りたいこと | あった場所 |
|---|---|
| 誰の結果を待っているか（戻り先） | コールスタック |
| 何周目か | ループの変数 |
| その周の呼び出し要求と、途中まで揃った結果 | 実行を担う関数のローカル変数 |
| 同じエージェントを使用中であること | `execute()` のロック |

関数が返った瞬間に、どれも消える。

## どうしたか

検討した案は3つ。

| 案 | 中身 | 採らなかった理由 |
|---|---|---|
| A. 待つ | tool の中で返事を待ってブロックする | プロセスが生きている間しか成り立たない。コンテナが0台まで落ちる・複数台に分かれる構成で壊れる |
| B. 関数のまま、止めたら巻き戻して再開時に組み直す | 親子は「親の枠に子のフレームが入っている」データで持つ | 普通の経路と再開の経路が2本になる。「中断をまたぐ状態をローカル変数に置かない」という規約を、ループに手を入れる人がずっと守り続けることになる |
| C. 記録と再生 | LLM と tool の結果を記録し、再開時は最初から再生して同じ地点まで戻る | 再生ではなく、文字通りの中断と再開がほしい。設定（プロンプトや `usage`）を変えると再生がずれる |

採ったのは、B の弱点の根を消す形。委譲を関数呼び出しから「表に行を足すこと」に変え、表を回す側（Network）が、進められる行を1段ずつ進める。

- **中断**は、進められる行が無くなったら止まるだけ。巻き戻しは要らない。
- **保存と復元**は、表と記憶を書き出す／読み込むだけ。
- **普通の実行と再開は、同じ表を回す同じ経路**を通る。最初の依頼は「行が1つの表」から回し始めるだけ。

並列の粒度は変えていない。同じバッチの呼び出しは並列に、同じエージェントの起動は1件ずつ。起動の途中の状態（実行履歴・周回数など）はエージェントの属性に持ったままで、同時に1つの起動しか属性を使わないことを表が保証する。エージェントのコードで手を入れたのは、待つ処理を含む所（ループの入口とバッチの前後）だけで、生成・記憶の更新・停滞の検出はそのまま使っている。

GoF で言えば、Network が仲立ちする Mediator、1回の起動が段階を持つ State、呼び出し要求を表に置ける形にする Command。保存した状態は Memento で、利用側は中身を見ずに保管して返すだけ。

## 引き換えに失うもの

- **中断できる場所は、tool の本体と `before_execute` のコールバックだけ。** 生成や記憶の更新の途中では止められない（止まった位置を表せる場所が、バッチの枠しか無い）。
- **tool の関数を途中から再開することはできない。** tool の本体で中断した場合、再開時に渡した答えがその tool の結果になる。`before_execute` で中断した場合は、同じ呼び出しを判定し直し、そこの `suspend()` が答えを返す。
- **LLM の生成と tool は、常にスレッドプールの側で動く。** 以前は、並列にならないバッチは呼び出したスレッドで動いていた。呼び出したスレッドに紐づく状態（スレッドローカルな接続など）を当てにした tool は動かない。
- **保存する状態は JSON にできる必要がある。** tool の戻り値と `suspend()` に渡す値に、JSON にできない型を入れると、保存の時点で `TypeError` になる。
- **エージェントを単体で動かす時は中断できない。** 保存して再開する入口は Network にしか無い。
